03 ✓
Crear entorno virtual
Aísla las dependencias del proyecto
~2 min
›
🧪Un entorno virtual es una caja aislada para tu proyecto. Evita conflictos con otros programas de Python en tu computador. Siempre hazlo.
Windows
macOS / Linux
# Crear el entorno virtual:
$ python -m venv venv

# Activarlo (debes hacer esto cada vez que abras la terminal):
$ venv\Scripts\activate

# Verás esto en tu terminal cuando esté activo:
(venv) $
$ python3 -m venv venv
$ source venv/bin/activate

# Verás esto cuando esté activo:
(venv) $
04 ✓
Instalar dependencias
Todas las librerías de IA en un comando
~5 min
›

Con el entorno virtual activado, ejecuta:

(venv) $ pip install -r requirements.txt

# Esto instala automáticamente:
# ✓ groq → LLM gratis ultra-rápido (LLaMA 3.3 70B)
# ✓ chromadb → Base de datos vectorial local
# ✓ sentence-transformers → Embeddings locales
# ✓ beautifulsoup4 → Leer páginas web
# ✓ pypdf → Leer PDFs
# ✓ python-dotenv → Variables de entorno
⏳La primera vez tarda 3-8 minutos porque descarga los modelos de embeddings (~90MB). Las siguientes veces es instantáneo.
✅Si ves Successfully installed... al final, todo está bien.
05 ✓
Obtener tu API Key GRATIS
Groq: LLaMA 3.3 70B sin costo
~3 min
›
🎁100% GRATIS. Groq ofrece acceso gratuito a LLaMA 3.3 70B (el mejor modelo open source). Límite generoso: ~14,400 requests/día gratis. Sin tarjeta de crédito.
  • Ir a console.groq.com y crear cuenta gratuita
  • Ir a "API Keys" → "Create API Key"
  • Copiar la clave (empieza con gsk_)
  • Pegar la clave en el archivo config/.env
# Abrir config/.env con cualquier editor de texto y poner:

GROQ_API_KEY=gsk_TU_CLAVE_REAL_AQUI
🔒El archivo config/.env nunca sale de tu computador. Tu API key está segura.
